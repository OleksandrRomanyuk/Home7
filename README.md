
# Box Model — Навчальні картки

## Мета проєкту

Створити дві навчальні картки для демонстрації
роботи з CSS Box Model, розмірами, відступами
та позиціюванням елементів.

## Використані технології

- HTML5
- CSS3

## Використані CSS-властивості

- **box-sizing: border-box** — враховує padding
  і border у загальній ширині елемента.
- **padding** — створює внутрішні відступи.
- **border** — додає рамки карткам.
- **margin** — визначає зовнішні відступи.
- **position: relative** — задає контекст
  позиціювання для позначки.
- **position: absolute** — розміщує позначку
  відносно першої картки.
- **overflow-wrap: break-word** — допомагає
  уникати виходу довгих слів за межі картки.
- **max-width** — обмежує максимальну ширину карток.

## Перевірка в DevTools

Розміри двох карток і позиціювання позначки
перевірено в DevTools. У вкладці Elements
за допомогою Box Model можна переглянути
content, padding, border і margin.

На вузькій ширині позначка не перекриває
заголовок, а горизонтальний скрол сторінки відсутній.
